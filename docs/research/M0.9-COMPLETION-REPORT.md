### Build Reproducibility Problem

**Issue:** Repository's normal build path contains unresolved issue. `project/winres.rc` prevents standard Windows executable build due to icon format error (RC2175).

**Workaround Used:** Temporarily excluded icon resource from CMakeLists.txt, built executable, reverted CMakeLists.txt. This workaround was NOT committed.

**Impact:** Cannot repeatedly rely on manual workaround. Build infrastructure has reproducibility problem.

**Resolution Options:**
- Fix icon format (convert to RC-compatible 3.00 format)
- Make icon optional via CMake flag
- Remove icon resource entirely

**Status:** Build succeeded with workaround. Executable created but runtime functionality not yet verified via smoke test.

### Known Build Issues
### Known Build Issues

1. **Icon Resource Error (Non-Critical)**
   - Error: `RC2175: resource file icon.ico is not in 3.00 format`
   - Impact: Server executable not built, but test executable succeeded
   - Workaround: Icon is cosmetic, does not block development
   - Status: Documented, tracked for future fix

2. **bcrypt CMake Conflict (Auto-Fixed)**
   - Issue: bcrypt requires CMake 2.8, conflicts with CMake 4.x
   - Fix: Automatic patch during first build
   - Status: Resolved

3. **vswhere Missing (Non-Blocking)**
   - Issue: `build-windows.ps1` requires vswhere in PATH
   - Workaround: Use direct CMake configuration
   - Status: Documented

## Bug #4 Investigation Strategy

### Status: UNPROVEN

Phase 0.5 analysis suggested potential timer double-free, NOT arena use-after-free. Requires runtime testing to confirm.

### Investigation Plan

1. **Build with AddressSanitizer**
   - MSVC flag: `/fsanitize=address`
   - Detects use-after-free, double-free, memory corruption

2. **Create Reproduction Test**
   - Trigger map reload during `arena_spawn()` timer callback
   - Force arena destruction with active timer

3. **Analyze ASan Output**
   - If ASan detects issue: Bug confirmed, implement fix
   - If no ASan errors: False positive OR bug does not exist

4. **Document Findings**
   - Update `docs/arena/LEGACY-ARENA-BUGS.md`
   - Change Bug #4 status to PROVEN/DISPROVEN/FIXED
